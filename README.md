## 📌 О проекте / Overview

**`DnsEquipmentLedger`** — десктопное приложение на платформе **WPF (.NET 8)**, разработанное для автоматизации инвентарного учёта техники в филиале розничной сети **«ДНС»**.

Система обеспечивает полный цикл отслеживания материальных ценностей: от первичной постановки оборудования на учёт и закрепления за материально ответственным лицом (МОЛ) до регистрации истории перемещений между отделами филиала (склад, торговый зал, сервисный центр).

### 🖼️ Интерфейс главного окна приложения
> *Мгновенный поиск по инвентарному/серийному номеру, модели и ФИО ответственного, фильтрация по категориям и реактивное обновление реестра.*

## 🏗️ Архитектура и выполнение технических требований

Проект спроектирован с соблюдением принципов **SOLID**, чистого разделения слоёв (**MVVM**) и классических шаблонов проектирования (**GoF / Enterprise**):

| Требование / Компонент | Реализация в проекте | Файлы исходного кода |
| :--- | :--- | :--- |
| **UI-платформа (WPF)** | Чистая XAML-вёрстка в фирменном стиле «ДНС» с использованием `DataBinding` и `ObservableCollection`. Полное отсутствие бизнес-логики в `Code-Behind`. | `MainWindow.xaml` |
| **Архитектура MVVM** | Разделение данных (`Models`), представления (`Views`) и логики состояния экрана (`ViewModels`). | Папки `Models/`, `Views/`, `ViewModels/` |
| **Паттерн №1: Repository** | Изоляция контекста БД от `ViewModel`. Инкапсуляция выборок с жадной загрузкой связей (`Include`). | `Data/EquipmentRepository.cs` |
| **Паттерн №2: Command** | Реализация интерфейса `ICommand` для привязки кнопок интерфейса без обработчиков `Click`. | `ViewModels/MainViewModel.cs` (`RelayCommand`) |
| **Паттерн №3: Observer** | Уведомление интерфейса об изменениях свойств в реальном времени через `INotifyPropertyChanged`. | `ViewModels/MainViewModel.cs` |
| **ORM + Авто-миграция БД** | **Entity Framework Core (Code-First)**. Автоматическое создание БД, накатывание миграций (`Database.Migrate()`) и начальное заполнение (`Data Seeding`) при старте программы. | `Data/AppDbContext.cs`, `App.xaml.cs`, `Migrations/` |

## 🗄️ Схема базы данных (Третья нормальная форма — 3НФ)

Реляционная база данных спроектирована в нотации **Crow's Foot («Воронья лапка»)** в Microsoft Visio (исходный файл `dns_equipment_ledger.vsdx` включён в репозиторий) и нормализована до **3НФ** — все атрибуты атомарны, отсутствуют частичные и транзитивные функциональные зависимости:

![ERD-диаграмма базы данных в 3НФ](https://i.imgur.com/piuv9Qs.png)

### Описание таблиц (Сущностей):
1. **`Categories` (Категории техники)** — справочник видов оборудования (*Торговое и кассовое, Компьютеры и ноутбуки, Сетевое оборудование*).
2. **`Manufacturers` (Производители / Бренды)** — справочник брендов (*DEXP, ARDOR GAMING, Honeywell, АТОЛ*) и контактов сервисной поддержки.
3. **`Locations` (Локации филиала «ДНС»)** — физические зоны размещения (*Основной склад, Торговый зал, Сервисный центр*).
4. **`Employees` (Сотрудники / МОЛ)** — материально ответственные лица филиала с контролем уникальности табельного номера (`Unique Index`).
5. **`EquipmentItems` (Единицы техники)** — центральная таблица реестра с контролем уникальности инвентарного номера (`InventoryNumber`), балансовой стоимостью и текущим статусом.
6. **`EquipmentMovements` (Журнал учёта движений техники)** — исторический лог всех операций с техникой (*Первичная приёмка, Перемещение, Ремонт, Списание*) с защитой от каскадных циклов удаления (`DeleteBehavior.Restrict`).

## 📂 Структура проекта / Project Structure

- **`Data/AppDbContext.cs`** — Контекст EF Core, Fluent API индексы, настройка внешних ключей и `Data Seeding`.
- **`Data/EquipmentRepository.cs`** — Реализация паттерна `Repository` для изолированного доступа к данным.
- **`Migrations/`** — Автоматическая миграция схемы БД (`InitialCreate`), сгенерированная по подходу Code-First.
- **`Models/Entities.cs`** — 6 классов сущностей реляционной БД в 3НФ с атрибутами валидации и точными типами данных SQL.
- **`ViewModels/MainViewModel.cs`** — Логика фильтрации, поиска и реализация паттернов `Command` (`RelayCommand`) и `Observer` (`INotifyPropertyChanged`).
- **`App.xaml.cs`** — Точка входа с автоматическим применением миграций `db.Database.Migrate()` при старте.
- **`MainWindow.xaml`** — Главный экран реестра техники в фирменном стиле «ДНС».
- **`dns_equipment_ledger.vsdx`** — Исходный чертёж ERD-диаграммы базы данных в формате Microsoft Visio.

## 🚀 Быстрый запуск (Zero-Configuration)

Проект **не требует** ручной установки SQL Server или выполнения внешних SQL-скриптов:

1. Склонируйте репозиторий в терминале (`git clone https://github.com/lafro6978/DnsEquipmentLedger.git`) или откройте его напрямую через Visual Studio.
2. Откройте решение **`DnsEquipmentLedger.sln`** в **Visual Studio 2022** (требуется установленный компонент *.NET 8.0 Desktop Development*).
3. Нажмите **`F5` (Запуск)**. При старте автоматически выполнится миграция `db.Database.Migrate()`, которая создаст локальный файл базы данных `dns_equipment_ledger.db` и заполнит все 6 таблиц демонстрационными данными филиала «ДНС».
