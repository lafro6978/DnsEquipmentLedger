# Электронная книга учёта техники филиала «ДНС» (DnsEquipmentLedger)

Десктопный программный модуль для автоматизации корпоративного учёта оборудования, материально ответственных лиц (МОЛ), складских/торговых локаций и истории перемещений техники в филиале розничной сети «ДНС».

## Стек технологий и архитектура
* **Платформа и язык:** C# 12, .NET 8.0
* **Пользовательский интерфейс:** Windows Presentation Foundation (WPF, чистый XAML + Data Binding)
* **Архитектурный паттерн:** MVVM (Model — View — ViewModel)
* **Шаблоны проектирования (GoF / Enterprise):**
  * **Repository (`EquipmentRepository`)** — изоляция бизнес-логики и ViewModel от прямых запросов к контексту БД.
  * **Command (`RelayCommand`)** — обработка пользовательских действий через `ICommand` без использования событий в Code-Behind (`MainWindow.xaml.cs`).
  * **Observer (`INotifyPropertyChanged`)** — реактивное обновление таблиц и фильтров интерфейса.
* **Работа с базой данных (ORM):** Entity Framework Core (SQLite), подход **Code-First**, настройка связей через **Fluent API**, автоматическое применение миграций при запуске (`Database.Migrate()`) и начальное заполнение справочников (**Data Seeding**).

## Схема базы данных (Третья нормальная форма — 3НФ)
Реляционная база данных спроектирована в нотации Crow's Foot (исходная схема в формате MS Visio `dns_equipment_ledger.vsdx` находится в корне репозитория) и приведена к **3НФ**:
1. **`Categories`** — справочник категорий оборудования.
2. **`Manufacturers`** — справочник производителей и контактов сервисной поддержки.
3. **`Locations`** — локации и помещения филиала (склад, торговый зал, сервисный центр).
4. **`Employees`** — материально ответственные лица (МОЛ) с контролем уникальности табельного номера.
5. **`EquipmentItems`** — центральный реестр единиц техники с уникальным индексом по инвентарному номеру.
6. **`EquipmentMovements`** — журнал учёта операций (первичная приёмка, перемещение между локациями, ремонт, списание).

## Быстрый запуск
Приложение не требует ручной установки СУБД или выполнения SQL-скриптов:
1. Клонируйте репозиторий и откройте решение `DnsEquipmentLedger.sln` в Visual Studio 2022.
2. Нажмите **F5 (Запуск)** — при старте сработает автоматическая миграция EF Core, которая создаст локальную БД `dns_equipment_ledger.db` и заполнит её демонстрационными данными филиала «ДНС».
